# Q5: pi-subagents API — Agent Tool, AgentManager, Symbol.for, Return Values

## Summary

The `@tintinweb/pi-subagents` package (v0.7.3) exposes three LLM-callable tools (`Agent`, `get_subagent_result`, `steer_subagent`), a `Symbol.for("pi-subagents:manager")` global registry key set synchronously at module-init time, and an `AgentManager` class providing `spawn()` for background fire-and-forget and `spawnAndWait()` for foreground blocking dispatch. Subagent results are returned as strings via `AgentRecord.result` (or `AgentRecord.error` on failure). Model selection supports exact `provider/modelId` strings and fuzzy short-names (`"haiku"`, `"sonnet"`).

## `Agent` Tool — Parameter Contract

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `prompt` | `string` | **yes** | — | The task for the agent to perform |
| `description` | `string` | **yes** | — | Short 3-5 word summary (shown in UI) |
| `subagent_type` | `string` | **yes** | — | `"general-purpose"`, `"Explore"`, `"Plan"`, or custom name from `.pi/agents/<name>.md` |
| `model` | `string` | no | inherit parent | `"provider/modelId"` or fuzzy name (`"haiku"`, `"sonnet"`) |
| `thinking` | `string` | no | inherit parent | `off`, `minimal`, `low`, `medium`, `high`, `xhigh` |
| `max_turns` | `number` (min 1) | no | unlimited | Maximum agentic turns before graceful shutdown |
| `run_in_background` | `boolean` | no | `false` | Run without blocking; returns agent ID immediately |
| `resume` | `string` | no | — | Agent ID to resume a previous session |
| `isolated` | `boolean` | no | `false` | No extension/MCP tools — only built-in tools |
| `isolation` | `"worktree"` | no | — | Run in an isolated git worktree |
| `inherit_context` | `boolean` | no | `false` | Fork parent conversation into the agent |
| `schedule` | `string` | no | — | Cron/interval/one-shot schedule |

- **Source:** README; `src/index.ts` TypeBox schema
- **Frontmatter authority:** If an agent config `.md` file sets `model`, `thinking`, `max_turns`, `inherit_context`, `run_in_background`, `isolated`, or `isolation`, those values are locked and `Agent` tool parameters only fill unspecified fields.

## `Symbol.for("pi-subagents:manager")` Registration Pattern

Registration is **synchronous at module-init time** (require-time / import-time), not lazy. The code in `src/index.ts`:
```typescript
const MANAGER_KEY = Symbol.for("pi-subagents:manager");
(globalThis as any)[MANAGER_KEY] = {
  waitForAll: () => manager.waitForAll(),
  hasRunning: () => manager.hasRunning(),
  spawn: (piRef: any, ctx: any, type: string, prompt: string, options: any) =>
    manager.spawn(piRef, ctx, type, prompt, options),
  getRecord: (id: string) => manager.getRecord(id),
};
```
On `session_shutdown`, the key is deleted: `delete (globalThis as any)[MANAGER_KEY];`.

- **Source:** `src/index.ts` (around line ~300)
- **Standard pattern:** "Standard Node.js pattern for cross-package singletons (used by OpenTelemetry, etc.)"

## Subagent Return Values

Returned via `AgentRecord` struct:
```typescript
interface AgentRecord {
  id: string;
  type: SubagentType;
  description: string;
  status: "queued" | "running" | "completed" | "steered" | "aborted" | "stopped" | "error";
  result?: string;          // final response text
  error?: string;           // error message if status === "error"
  toolUses: number;
  startedAt: number;
  completedAt?: number;
  session?: AgentSession;
}
```

- **`spawnAndWait()`**: Returns `Promise<AgentRecord>` — resolved record with `record.result` or `record.error`.
- **`spawn()`**: Returns agent ID string. On completion, `onComplete` callback fires with `AgentRecord`. LLM receives structured XML `<task-notification>` with result. Results retrievable via `get_subagent_result` tool. Transcripts streamed to `<cwd>/.pi/output/agent-<id>.jsonl`.

## Model Tier Designations and Model Selection

**Model resolution** (`src/model-resolver.ts`):
1. Exact match: `"provider/modelId"` — resolved via registry, only if available (auth configured)
2. Fuzzy match: Scoring against all available models — exact ID match (100) > substring (60+) > name contains (40+) > scattered parts (20). Min score: 20.
3. Fallback: Returns error listing all available models

**Default agent models** (`src/default-agents.ts`):
- `Explore`: hardcoded to `"anthropic/claude-haiku-4-5-20251001"` (falls back to parent if unavailable)
- `general-purpose` and `Plan`: inherit parent's model

**Precedence** (`src/invocation-config.ts`):
```
modelInput = agentConfig?.model ?? params.model
```
Agent config (`.md` file) values take priority over `Agent` tool call parameters.
