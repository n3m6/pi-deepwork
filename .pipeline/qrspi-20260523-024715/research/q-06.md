# Q6: pi-subagents Agent Type .md Files — Discovery, YAML Frontmatter Schema, File Naming

## Summary
The `@tintinweb/pi-subagents` package discovers custom agent-type `.md` files from two directory locations (project-local `.pi/agents/` and global `~/.pi/agent/agents/`), with project-level files overriding same-named global ones. Each file uses YAML frontmatter with 15 supported fields (all optional), and the markdown body becomes the agent's system prompt. The filename (minus `.md`) becomes the agent type name.

## File Naming Convention
- **Extension:** `.md` only
- **Name derivation:** `basename(file, ".md")` becomes the agent type name
- Any filename is allowed; names matching built-in defaults (`general-purpose`, `Explore`, `Plan`) override them.
- **Source:** `src/custom-agents.ts:43-48`

## Directory Discovery Order (Priority)

| Priority | Path | Scope |
|----------|------|-------|
| 1 (highest) | `<cwd>/.pi/agents/*.md` | Project-local |
| 2 | `$PI_CODING_AGENT_DIR/agents/*.md` (default: `~/.pi/agent/agents/*.md`) | Global |

- Source: `src/custom-agents.ts:10-15` (JSDoc), `src/custom-agents.ts:22-25`
- Global-loaded agents inserted first (lower priority), then project agents overwrite same-named entries.
- Within each directory, all `.md` files are loaded — no internal ordering.

**Registered agent types merge order** (from `src/agent-types.ts:31-42`):
1. `DEFAULT_AGENTS` (embedded: `general-purpose`, `Explore`, `Plan`)
2. User-defined agents from custom `.md` files (overlays defaults with same name)
Case-insensitive lookup at resolution time.

## Complete YAML Frontmatter Schema

Every field is optional. Derived from `src/custom-agents.ts:70-87` and `src/types.ts:35-79`:

| Field | YAML key | Type | Default | Valid values |
|-------|----------|------|---------|--------------|
| **description** | `description` | `string` | `name` (filename) | Any string |
| **display_name** | `display_name` | `string` (optional) | `undefined` | Any string |
| **tools** | `tools` | comma-separated string | All 7 built-in tools | Subset of: `read, bash, edit, write, grep, find, ls`, or `none` |
| **extensions** | `extensions` / `inherit_extensions` | `true` \| `string[]` \| `false` | `true` | `true` (inherit all), `false` (none), `"none"` (same as false), or comma-separated extension names |
| **skills** | `skills` / `inherit_skills` | `true` \| `string[]` \| `false` | `true` | Same semantics as `extensions` |
| **disallowed_tools** | `disallowed_tools` | comma-separated string (optional) | `undefined` | Comma-separated tool names to block |
| **model** | `model` | `string` (optional) | `undefined` (inherit parent) | `provider/modelId` or fuzzy name (`"haiku"`, `"sonnet"`) |
| **thinking** | `thinking` | `string` (optional) | `undefined` (inherit parent) | `off`, `minimal`, `low`, `medium`, `high`, `xhigh` |
| **max_turns** | `max_turns` | `number` (optional) | `undefined` (unlimited) | Non-negative integer. `0` = unlimited |
| **prompt_mode** | `prompt_mode` | `string` | `"replace"` | `"replace"` or `"append"` |
| **inherit_context** | `inherit_context` | `boolean` (optional) | `undefined` (caller decides) | `true` / `false` |
| **run_in_background** | `run_in_background` | `boolean` (optional) | `undefined` (caller decides) | `true` / `false` |
| **isolated** | `isolated` | `boolean` (optional) | `undefined` (caller decides) | `true` / `false` |
| **memory** | `memory` | `string` (optional) | `undefined` | `"project"`, `"local"`, `"user"` |
| **isolation** | `isolation` | `string` (optional) | `undefined` | `"worktree"` |
| **enabled** | `enabled` | `boolean` | `true` | `true` / `false`. `false` hides from spawning |

Parsing details from `src/custom-agents.ts:90-136`:
- `str(val)`: only exact `typeof val === "string"`, otherwise `undefined`
- `nonNegativeInt(val)`: only exact `typeof val === "number" && val >= 0`, otherwise `undefined`
- `prompt_mode`: anything other than literal `"append"` → `"replace"`
- `inheritField`: omitted/null/`true` → `true`; `false`/`"none"` → `false`; comma-separated → `string[]`; empty → `false`
- `memory`: only `"user"` / `"project"` / `"local"`; anything else → `undefined`
- `isolation`: only literal `"worktree"` → `"worktree"`; else → `undefined`
- `enabled`: `fm.enabled !== false` → default `true`

## Semantics of `tools` Field

- **Default (omitted):** All 7 built-in tools: `read`, `bash`, `edit`, `write`, `grep`, `find`, `ls`.
- **"none":** Intended for empty tools. But `getToolNamesForType` in `src/agent-types.ts:138-141` checks `config?.builtinToolNames?.length ?` — empty array has `length: 0` (falsy), so it falls back to all 7 tools. This means `tools: "none"` currently results in all tools.
- **Enumerated list:** e.g. `tools: read, grep, find` — parsed via `parseCsvField`.
- **There is no literal value `"all"`** — not specially handled. `tools: all` would parse to `["all"]`, which doesn't match any built-in.

## How `disallowed_tools` Interacts with `tools`

The denylist is a **post-filter** applied after the full tool set is assembled (`src/agent-runner.ts`). Tools are first resolved from `builtinToolNames` and extensions, then `disallowedTools` set removes any matching tool name — regardless of whether it was built-in or extension-provided.

The extension's own tools (`Agent`, `get_subagent_result`, `steer_subagent`) are always excluded from sub-agents via `EXCLUDED_TOOL_NAMES` regardless of denylist.

## `prompt_mode` Semantics

- **`replace` (default):** Agent's system prompt body is the full system prompt. Does NOT inherit `AGENTS.md`/`CLAUDE.md`. Environment block prepended.
- **`append`:** Body appended to parent's system prompt. Agent inherits parent's `AGENTS.md`/`CLAUDE.md`, rules, conventions. A `<sub_agent_context>` bridge block inserted.

## Frontmatter Locking

Frontmatter values for `model`, `thinking`, `max_turns`, `inherit_context`, `run_in_background`, `isolated`, and `isolation` are **locked** for that agent type — the `Agent` tool call parameters only fill in values the agent config leaves unspecified. For `inherit_context`, `run_in_background`, `isolated`, `undefined` when omitted means the caller decides.

## Default Agent Configurations

| Agent | `builtinToolNames` | `model` | `promptMode` |
|-------|-------------------|---------|-------------|
| `general-purpose` | omitted (all 7) | inherit | `append` |
| `Explore` | read, bash, grep, find, ls | `anthropic/claude-haiku-4-5-20251001` | `replace` |
| `Plan` | read, bash, grep, find, ls | inherit | `replace` |

All three: `extensions: true`, `skills: true`, `isDefault: true`.
